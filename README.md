# Handwritten Digit Recognition using Deep Learning

## Overview

This project recognizes handwritten digits (0–9) using Deep Learning and TensorFlow.
Users can draw digits on a GUI canvas, and the AI model predicts the digit in real time.

## Features

* Handwritten digit prediction
* GUI drawing interface
* Real-time AI prediction
* Deep learning model
* MNIST dataset implementation

## Technologies Used

* Python
* TensorFlow
* Keras
* Tkinter
* NumPy
* Pillow

## Deep Learning Concepts

* Neural Networks
* Image Classification
* Softmax Activation
* Model Training

## Files

* `train_model.py` → Trains the AI model
* `digit_gui.py` → GUI application
* `digit_model.h5` → Saved trained model

## Dataset

MNIST Handwritten Digit Dataset

## How to Run

Install dependencies:

pip install tensorflow pillow numpy

Run the application:

python digit_gui.py


## Output

* Draw a digit using mouse
* Click Predict
* AI predicts the handwritten number
